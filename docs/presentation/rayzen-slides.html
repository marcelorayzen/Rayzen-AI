Foi o primeiro módulo com testes escritos. Whitelist inegociável — ações fora são rejeitadas silenciosamente.

🔒
Whitelist de comandos
Apenas 33 ações explicitamente permitidas. Qualquer comando fora da lista é bloqueado antes de executar.
🛡
Path traversal bloqueado
Toda operação de arquivo passa por sandbox de diretório. ../ bloqueado em todas as ações.
⚡
Dry-run para ações de risco
Ações de risco médio/alto descrevem o que fariam antes de executar.
